# FIEP — Backoffice Process Optimization & Automation

Executive one-page presentation for the **FIEP × Alpar — Backoffice Improvements & Automation** business case, built on ServiceNow.

Live page: published via **GitHub Pages** from this repository (`/index.html` on the default branch).

## Publish on GitHub Pages

1. Push this branch and merge to `main` (or set Pages to serve from this branch).
2. Repository → **Settings → Pages**.
3. **Source:** *Deploy from a branch* → **Branch:** `main` → **Folder:** `/ (root)` → **Save**.
4. The page goes live at `https://<owner>.github.io/<repo>/`.

## Structure

Single-file `index.html` — no build step, no dependencies beyond Google Fonts. Animations are pure CSS + a small IntersectionObserver script for reveals, KPI counters and the workload bars.
